About this portfolio

Documented engineering and research work

This portfolio presents independent and coursework engineering projects carried out by {{ site.student_name }}. Each project page summarises the problem addressed, the method followed, the results obtained and the limitations of the work, and links to a permanent, citable record of the complete documentation.

Full reports, datasets and supporting materials are archived on Zenodo, an open research repository operated by CERN, where each record receives a permanent DOI. Where a project includes source code or hardware documentation, it is published on GitHub or Hackster.io and linked from the corresponding project page.

Each project page states clearly which parts of the work were experimentally carried out and which were conceptual, simulated or proposed for future testing.
